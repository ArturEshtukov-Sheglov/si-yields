# si-yields

Номера соединений, названия и выходы из Supporting Information (SI) химических статей.

Скрипт читает PDF-файлы SI и записывает таблицу, одна строка на соединение:

| label | name | yield_percent |
|---|---|---|
| 3c | (5R,6R,9R)-4-methyl-6-(naphthalen-2-yl)-2,7,9-triphenyl-9-vinyl-2,3,7-triazaspiro[4.4]non-3-ene-1,8-dione | 66 |
| 26 | | 81 |

и ещё колонки, которые помогают проверить результат (файл, пометка, страница, контекст).

Автор: Артур В. Ештуков-Щеглов (Artur V. Eshtukov-Shcheglov). Код написан с помощью
Claude Opus 5.5 (Anthropic), проверен и протестирован автором. Лицензия: MIT (файл LICENSE).

Основной является английская версия (README.md); это перевод для удобства.


## Что находит

Выход читается, если он записан в тексте SI в одной из обычных форм, например

    Colorless oil, (147.9 mg, 79% yield)
    White solid, m.p. 166-168 °C. 36.1 mg, 66% yield, >20:1 dr, 88% ee.
    ... to afford 3a in 72% yield (1.04 g).
    ... to afford, in order of elution, 17 (795 mg, 2.21 mmol, 45 %)
    Yield: 35% (91.8 mg)

Процент считается выходом, только если рядом стоит масса или количество (mg, g, mmol) или слово
«yield». Проценты, которые выходом не являются, пропускаются: ee, de, конверсия, чистота, состав
элюента («10-20% EtOAc in hexane»), реагенты («30% H2O2», «10% Pd/C»), ячейки таблиц и текст
схем реакций.

**Номер** берётся из заголовка соединения («... propanoate (3c)», «3a: white solid»,
«Compound 6a: ...») или из предложения с выходом («to afford 3a in 72% yield»).
**Название** — это текст перед номером в заголовке; оно остаётся пустым, если в SI есть только
номер или если название не удаётся отделить от окружающего текста.

Если у соединения несколько выходов (другие условия, синтез на граммовой загрузке, вторая
методика), в `yield_percent` записывается первый обычный выход, а остальные перечисляются в
`note`.


## Что нужно

Python 3.9 или новее и два пакета:

    python -m pip install -r requirements.txt

(`pymupdf` читает PDF, `openpyxl` пишет таблицу Excel; без `openpyxl` записывается только CSV.)


## Как запустить

**Проще всего:** положите PDF-файлы SI в папку `data/` и запустите

    python extract_yields.py

(Windows: двойной щелчок по `run.bat`; Linux: `bash run.sh`; macOS: двойной щелчок по
`run.command`; без установки: `si_yields_Colab.ipynb` в Google Colab). Все команды для всех
систем: [COMMANDS_RU.md](COMMANDS_RU.md). Результат записывается в `result/yields.xlsx` и
`result/yields.csv`. Файлы в `data/`, которые не являются PDF, перечисляются на экране и
пропускаются (SI в формате Word сначала сохраните как PDF).

**Другие файлы или другое имя результата:**

    python extract_yields.py SI_1.pdf SI_2.pdf
    python extract_yields.py путь/к/*.pdf -o yields_2026

В этом случае результат записывается в `yields.xlsx` и `yields.csv` (или в имя, указанное после
`-o`) в папке, из которой запущен скрипт.

Таблица с тем же именем перезаписывается; переименуйте её или используйте `-o`, чтобы сохранить
прежние результаты.

На экране для каждого файла: число соединений с выходом и сколько из них с названием. Файл,
который не удалось прочитать, называется на экране и пропускается; остальные файлы
обрабатываются.


## Колонки таблицы

| колонка | что означает |
|---|---|
| file | имя файла SI |
| label | номер соединения, как он написан в SI (3a, S10, (Sa)-L15, 4z') |
| name | название соединения, "" — не найдено |
| yield_percent | выход в % |
| note | что проверить: ЯМР-выход (NMR yield), граммовая загрузка (gram scale / scale-up), выход за несколько стадий (over several steps), суммарный выход (combined yield), brsm, «below the value given» (выход записан как «<5%»), другие выходы того же соединения со страницами, «label taken from the sentence, no heading» (номер взят из предложения, заголовка нет), «no name found» (название не найдено) |
| page | страница PDF с выходом |
| context | текст вокруг выхода, чтобы проверить строку, не открывая PDF |


## ВАЖНО: результат нужно проверять

Правила — это простые текстовые шаблоны. Сверяйте строки с колонкой `context`, а строки с
пометкой в `note` проверяйте по PDF.

Проверка на ~200 файлах SI статей по органической химии (~7500 соединений с выходом):

- при ручной проверке 100 случайных строк номер и выход были верными в 96; ошибки: процент
  реагента, принятый за выход («KH (290 mg, 30%, ...)»), выход из текста схемы, потерянный штрих
  в номере (3c вместо 3c') и один номер, который не удалось подтвердить;
- название найдено примерно для 80 % строк; примерно каждое десятое начинается с лишнего текста
  со страницы (номер страницы, подпись спектра, слово из предыдущего предложения), его нужно
  убрать вручную;
- из соединений, у которых в этих SI есть описание спектра ¹H ЯМР, выход получили около 88 %.
  У большинства остальных выхода в SI нет совсем (выходы даны только на схемах в статье).


## Ограничения

- Выходы, приведённые только в таблице или на схеме (в SI или в статье), не читаются.
- Выход приписывается номеру из ближайшего заголовка или предложения перед ним; если в одном
  абзаце описано несколько соединений, проверьте номер.
- Номера, которые есть только на рисунке структуры, не находятся.
- Текст берётся из PDF как есть: сканированные SI (картинки без текста) ничего не дают, а SI в
  формате Word нужно сначала сохранить как PDF.
- Читаются только проценты; выход, записанный дробью или только массой, не читается.
